Modellar reytingi

—

Skill = 1 − MAE(model) / MAE(persistence). Musbat qiymat — model "hozirgi qiymat o'zgarmaydi" degan oddiy prognozdan yaxshi. Qamrov — kuzatuv 80% ehtimollik oralig'iga tushgan ulush (ideal 0.80). Oqlanish — xatosi ruxsat etilgan chegaradan (δ = 0.674·σΔ, σΔ — konsentratsiyaning shu muddatdagi o'zgarishining standart chetlanishi) oshmagan prognozlar ulushi.
